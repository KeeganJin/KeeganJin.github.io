动态规划方法

动态规划基础

动态规划是强化学习的理论基础。

条件：

  • 完全已知MDP模型
  • 状态空间有限

值迭代（Value Iteration）

直接求解最优价值函数：

$V^(s) = \max_a \sum_{s’} P(s’|s,a)[R(s,a,s’) + \gamma V^(s’)]$

值迭代vs策略迭代

方面 值迭代 策略迭代
收敛速度 可能慢 通常快
每轮计算 单次更新 多次评估
适用 大状态空间 小状态空间

Q-Learning算法

Q-Learning原理

学习最优Q函数，无需环境模型。

更新公式：
$Q(s,a) \leftarrow Q(s,a) + \alpha[r + \gamma \max_{a’} Q(s’,a’) - Q(s,a)]$

Q-Learning算法

Q-Learning特点

特点 描述
Model-free 不需环境模型
Off-policy 可用任何数据学习
收敛性 保证收敛最优Q

SARSA算法

SARSA原理

同策略（On-policy）学习：
$Q(s,a) \leftarrow Q(s,a) + \alpha[r + \gamma Q(s’,a’) - Q(s,a)]$

SARSA vs Q-Learning

方面 Q-Learning SARSA
学习方式 Off-policy On-policy
目标 max Q(s’,a’) Q(s’,a’)
收敛 最优策略 当前策略

DQN及其变体

DQN原理

用神经网络近似Q函数：
$Q(s,a; \theta)$

创新点：

  • 经验回放
  • 目标网络

经验回放

作用：

  • 打破数据相关性
  • 提高样本利用效率

目标网络

作用：稳定训练目标

方法：

  • 主网络：Q(s,a; θ)
  • 目标网络：Q(s,a; θ’)
  • 定期更新θ’ ← θ

DQN实现

Double DQN

问题：DQN可能高估Q值。

解决：用策略网络选择行动，目标网络评估。

$Q_{target} = r + \gamma Q_{target}(s’, argmax_a Q_{policy}(s’, a))$

Dueling DQN

结构：分离状态价值和行动优势。

$Q(s,a) = V(s) + A(s,a) - \frac{1}{|A|}\sum_{a’} A(s,a’)$

Prioritized Experience Replay

思想：优先学习重要样本。

优先级：TD误差大小

基于价值方法总结

优点

优点 描述
算法成熟 理论基础完善
收敛保证 有收敛性证明
易实现 相对简单

缺点

缺点 描述
离散动作 不适合连续动作
状态有限 表格方法受限
探索难题 可能陷入局部最优

总结

基于价值的方法是强化学习的基础。核心内容包括：

  • 动态规划：值迭代、策略迭代
  • Q-Learning：Model-free学习最优Q
  • SARSA：On-policy学习
  • DQN：神经网络近似Q函数
  • DQN变体：Double DQN、Dueling DQN、Prioritized Replay

基于价值的方法适合离散动作空间，理论基础成熟。
