## What are Tree-based Models

Tree-based models are an important class of machine learning algorithms including Decision Trees, Random Forests, and Gradient Boosted Decision Trees (GBDT).

### Decision Tree

Decision trees make decisions through a tree structure where each internal node represents a test on a feature.

### Random Forest

Random Forest improves prediction accuracy by ensembling multiple decision trees.
